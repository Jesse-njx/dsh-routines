dsh-routines · v0.1

Scheduled agents
for DSH.

Run a prompt on a cron.
Get the digest where you already are.

what it is

A routine is
one YAML file.

Prompt + schedule + delivery — human-readable, git-committable.

routine file · .dsh/routines/nightly.yaml name: nightly-tests
schedule: "0 2 * * *"
timezone: Asia/Shanghai
prompt: run the tests, fix the top failure,
      summarize in <10 lines>
deliver: [file, chatnode]
why you want it

Your 2 a.m. chores,
done while you sleep.

Nightly test triage · morning briefs · dependency checks.

Laptop asleep? One honest catch-up run on wake — never a backlog replay.

how it works

Cron in. Digest out.

Each run is its own one-shot session — full audit log, replayable.

routine.yaml in your repo
→
schedulerctx.jobs · overlap · timeout
→
headless runown session · own profile
→
digestfile · chatnode
in the terminal

Four commands.
That's it.

$ dsh routines list # what's scheduled
$ dsh routines run nightly # run one right now
$ dsh routines pause nightly # stop it
$ dsh routines logs nightly # status · digest · session
safety defaults

Unattended,
not unsupervised.

Anything that would prompt is auto-denied and noted in the digest. Hard timeouts. No silent escalation.
